= Geometry Types Summary

Overview of the geometry types defined in the `org.apache.sis.geometry` module
(package `org.apache.sis.geometries` and its sub-packages).

== Interface hierarchy

The 55 interfaces of the `Geometry` hierarchy are shown below, split by theme.
All of them are `sealed`, so their permitted subtypes are fixed at compile time
and a `switch` over them can be exhaustive.
Implementation classes are omitted; see the `internal.shared` package.
A few analytic shapes (`BBox`, `OBBox`, `Plane`, `HyperPlane`, `Frustrum`) are classes
implementing `Geometry` directly, without an interface of their own.

Colours: white is a type of this diagram; *blue-grey* is a type detailed in another diagram
here, repeated only to anchor it; *grey* is a type declared outside this module.

=== Collections

`GeometryCollection` has a single interface subtype, `ProductCurve`, which is both a collection and a `Curve`.
Multi-geometries have no interface of their own: they are `GeometryCollection` instances whose
`getElementType()` restricts the elements, created by the `GeometryFactory` methods
`createMultiPoint`, `createMultiCurve`, `createMultiLineString`, `createMultiSurface`, `createMultiPolygon`
and `createMultiPolyhedron`. Several mesh primitives are grouped in a `GeometryCollection<MeshPrimitive>`.
The `Points` and `Lines` mesh primitives are themselves collections of points and of line segments.

== JTS backend

The methods below still delegate their computation to the https://locationtech.github.io/jts/[JTS Topology Suite]
(packages `org.locationtech.jts`). The geometry is viewed as a JTS geometry by `adapter.JTSAdapter`,
which supports only points, line strings, linear rings, polygons and collections of them:
other geometry types make those methods throw `UnsupportedOperationException` or `IllegalArgumentException`.
A geometry computed by JTS is converted back with the coordinate reference system of the operand,
but its points keep no attribute other than the position.

The conversions between both models (`adapter.JTSAdapter`, `Geometries.asJTS`, `Geometries.fromJTS`,
`adapter.Wrapper.asJTS`) are not listed: converting is their purpose.
